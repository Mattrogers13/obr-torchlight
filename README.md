# Torchlight

An Owlbear Rodeo extension for running the crawling phase of the Shadowdark RPG: torch timer (real-time or turn-based), crawl turn counter, and random encounter roller.

Based on [Shadow Crawler](https://github.com/alvarocavalcanti/shadowcrawler) by Alvaro Cavalcanti, used under the MIT License. This is an independent, customized copy and is not affiliated with or maintained by the original author.
